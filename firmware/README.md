# Proshivka manba kodi

To'liq hujjat: [../README.md](../README.md).

- `src/main.cpp` - datchiklar, Wi-Fi, telemetriya, sozlash sahifasi, serial buyruqlar
- `src/ota.cpp` - masofadan yangilash (tekshirish, SHA-256, avtomatik qaytish)
- `src/net.cpp` - HTTPS (faqat o'z serverimiz), JSON yordamchilari
- `include/config.h` - versiya, manzillar, pinlar, vaqtlar
- `include/root_ca.h` - Let's Encrypt ildiz sertifikatlari (X1, YR, X2, YE)
